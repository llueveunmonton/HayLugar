HAY LUGAR — DEMO PARA DEPLOY

1. Descomprimí el ZIP.
2. Subí index.html, style.css, app.js y la carpeta assets al directorio público de tu hosting estático.
3. Serví la web por HTTPS: la generación y copia de códigos utiliza funciones seguras del navegador.

No requiere instalación de dependencias, build ni servidor de aplicación.
Los archivos HTML, CSS y JavaScript son el código fuente editable.
Las tipografías se cargan desde Google Fonts; si no están disponibles se usan fuentes del sistema.
Las fuentes de las fotografías están en assets/sources.json.

ALCANCE
Esta es la demo construida de Hay lugar. Las ofertas y los locales son ficticios.
Reservas, códigos y nuevas promociones viven solo en la página abierta: se pierden al recargar y no se comparten entre dispositivos.
La vista del local es una simulación sin autenticación. No hay pagos ni notificaciones a restaurantes.
El plan comercial posterior todavía no fue implementado.
Para operar con clientes reales hacen falta almacenamiento compartido, cuentas de locales y control de cupos en servidor.
